# AI-Powered Dataset Explorer

## Overview

An interactive data analysis dashboard built using Python and Streamlit. The application allows users to upload CSV datasets and perform Exploratory Data Analysis (EDA).

## Features

- Dataset Preview
- Dataset Shape
- Column Information
- Missing Value Analysis
- Statistical Summary
- Histograms
- Correlation Matrix
- Correlation Heatmap

## Tech Stack

- Python
- Pandas
- Streamlit
- Matplotlib
- Seaborn
